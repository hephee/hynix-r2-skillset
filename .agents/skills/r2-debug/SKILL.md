# 재현과 원인 수정

1. 기대 결과·실제 결과·직전 변경을 확인하고 첫 실패를 작은 입력·명령으로 재현한다.
2. 증거에 맞는 가설을 세우고 가설을 구분할 확인을 한다. 여러 설정을 한꺼번에 바꾸지 않는다.
3. 원인만 수정하고 같은 재현 명령과 영향받는 검사로 확인한다.
4. PRD에 실패와 수정·재검증을 연결해 남긴다.

서버 연결은 오류·프로세스→실제 포트→바인딩→경로 순으로 확인한다. 플랫폼 권한·감독·API 장애면 시각·단계·오류를 정리해 신고하며 우회하지 않는다.
