# 세션 인수인계

PRD와 실제 파일을 대조해 다음 내용을 짧게 전달한다.

- 과제 루트·적용 지침·목표·필수 제출물.
- 확정된 결정·남은 가정·최근 작업 요약.
- 구현 상태·실행 명령·유지할 서버.
- 검증 명령·결과·미확인·실패 재현법.
- 마지막으로 확인한 과제 타이머·확인 시점·다음 한 작업.

별도 요청 없이는 인계 파일을 늘리지 않고 PRD·대화로 전달한다. 새 세션은 실제 상태를 다시 대조한다. 제출물이 확정됐다면 AI 작업을 재개하지 않는다.
