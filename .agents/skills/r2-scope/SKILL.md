# 요구 정리

1. 실제 README·기존 지침·파일 구조·실행 방법을 확인한다. 데이터는 작은 표본부터 읽는다.
2. `필수 요구 | 근거 | 기대 동작·값 | 제출 위치`를 정리한다. 가이드의 예시를 실제 과제 요구사항으로 옮기지 않는다.
3. 결과가 달라지는 미확정 정의만 질문하고 독립 작업은 진행한다.
4. 실제 남은 시간 안에 구현·검증 가능한 핵심 흐름을 정한다. 기준이 충분하면 계획 다듬기를 멈추고 구현으로 넘긴다.
