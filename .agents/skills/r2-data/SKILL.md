# 데이터 정의와 계산 확인

원본을 보존하고 행의 의미·키·시간·단위·검사 단계·제외 조건을 먼저 확인한다.

- 집계: 분자·분모의 모집단을 맞추고 분모 0·결측·가중 평균을 구분한다.
- 조인: 키 유일성과 결합 전후 행 수·개체 수·총량을 확인한다.
- 수율: 검사 시도와 제품, 결함 사건과 불량 제품을 구분한다. 재검사의 최초·최종 판정은 업무 정의를 따른다.
- 비교·시계열: 생산량·조건·단위·시간을 맞추고 상관을 원인으로 단정하지 않는다. 관리한계와 제품 규격도 구분한다.
- 예측: 예측 시점에 없는 정보, 분할 간 동일 개체·lot·wafer 중복, 미래 정보 유입을 막고 기준선과 비교한다.

작은 입력의 기대값과 결과를 대조하고 대상·기간·제외·분모·한계를 남긴다. 실제 임계값은 과제 기준을 따르며 공정 조작·승인으로 확대하지 않는다.
