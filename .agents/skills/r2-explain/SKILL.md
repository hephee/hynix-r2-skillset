# 본인 말로 설명하기

PRD와 실제 코드·검증 기록으로 다음 두 가지를 설명한다.

1. 핵심 기능, 대표 입력→처리→출력, 구현 방법·선택 이유·한계.
2. 사용한 AI 도구·스킬, 맡긴 일, 검증 대상·방법·관찰 결과와 실패 후 조치.

구현하지 않은 기능·측정하지 않은 효과를 만들지 않는다. 연습 요청이면 질문 하나를 하고 사용자 답을 기다린 뒤 오류·근거 누락만 짚는다. 예상 출제 문항·모범답안을 만들지 않는다. 제출물 확정 전 끝내며 단계가 불명확한 실제 문항이면 먼저 확인한다.
