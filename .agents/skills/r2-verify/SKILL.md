# 제출 전 확인

- `요구 | 확인 방법 | 실제 결과 | 통과·실패·미확인`으로 대조한다. 파일 존재만으로 통과시키지 않는다.
- 핵심 흐름과 중요한 경계·실패 사례를 확인한다. 새 기능 테스트, 계산 기대값, 저장 후 읽기를 필요에 맞게 점검한다.
- 유효한 기존 검증은 재사용하고 실패 수정의 영향 범위만 재확인한다.
- PRD의 기능·구현 요약과 AI 도구·스킬 검증 요약이 현재 코드·증거와 맞는지 확인한다.
- 화면 자동화 없이 사용자 수동 점검 절차를 준다. 확인 전에는 미확인이다.
- 필수 경로·저장 충돌·제출 여유를 확인하고 사용자에게 제출을 맡긴다. 미리보기는 파일 일부만 표시할 수 있다.
