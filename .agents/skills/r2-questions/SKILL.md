# 결정에 필요한 질문

- 실제 안내·데이터·PRD에서 이미 답한 내용을 먼저 확인한다.
- 질문에는 관찰 사실, 가능한 해석, 결과 차이를 짧게 넣는다. 지금 막힌 결정부터 묻는다.
- 사용자가 전달할 질문을 작성하며 직접 전송하거나 담당자 답변을 꾸미지 않는다.
- 답이 오면 기존 가정과 비교해 영향받는 요구·구현·검증만 갱신한다. 남은 불확실성은 표시한다.
